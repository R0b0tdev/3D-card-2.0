# MIR SUPREME · 3D-реконструкция ювелирной карты

## Просмотр

Открыть **http://localhost:8765/**. Для повторного запуска в Windows — дважды нажать `start-viewer.cmd`. Сервер использует установленный Ubuntu WSL и Python. В Ubuntu можно запустить `bash start-viewer.sh`. Доступ ограничен этим компьютером (127.0.0.1).

Свободное вращение мышью / одним пальцем без ограничения углов по всем осям; масштаб колёсиком / двумя пальцами. Можно проходить через верх и низ модели и делать несколько полных оборотов подряд. Кнопка сброса восстанавливает исходную ориентацию. Кнопки лицевой и обратной стороны, автовращение 360°, приближение, сброс, полный экран. Три фона, регулировка света, просмотр чистой геометрии и сохранение текущего ракурса PNG. Все библиотеки и материалы находятся локально; интернет для просмотра не требуется. При программном WebGL без GPU прозрачность камней упрощается автоматически, чтобы сохранить отзывчивость.

## Основные файлы

- `output/jewellery-card.blend` — мастер Blender 4.5.3 LTS, текстуры упакованы, материалы и студийный свет сохранены.
- `output/jewellery-card.glb` — переносимая модель glTF 2.0 с материалами и сжатой Draco геометрией, загруженная в просмотрщик.
- `output/studio-front.png` — студийный рендер.
- `output/cutout-mask.png` — маска вырезов: белое означает отверстие.
- `output/mask-review.jpg` — визуальная проверка маски поверх лицевой фотографии; бирюзовые области вырезаются.
- `output/metrics.json` — размеры и результат проверки геометрии.
- `source/` — неизменённые четыре исходника пользователя.
- `textures/` — производные карты цвета, нормалей, металличности, шероховатости и перламутра.
- `prepare.py`, `build_blender.py` — воспроизводимая подготовка и сборка.
- `tools/blender-4.5.3-linux-x64/blender` — установленный портативный Blender для Linux.

## Что построено

Габарит 53,98 × 85,60 мм, радиус четырёх углов 3,18 мм. Толщина основы принята 0,76 мм; рельеф и камни выступают за неё. Две стороны совмещены переворотом вокруг горизонтальной оси X. Изображение обратной стороны читается в исходной ориентации при соответствующем перевороте. Корпус — замкнутая сетка с общими для обеих сторон сквозными отверстиями и золотыми внутренними стенками, а не две плоскости с прозрачностью.

24 отверстия занимают приблизительно 4,68% площади карты. 504 отдельно построенных камня (256 / 248) с фасетами и золотыми кольцевыми оправами. Мелкие детали и орнамент передаются сочетанием геометрического микрорельефа, исходных normal map и карт материалов. Не каждый бриллиант и не каждая линия орнамента являются отдельным объектом: тонкая детализация остаётся в текстурах и рельефе общей поверхности.

Жёлтое золото настроено как металл; белые камни — как оптический материал бриллианта; розовые — как интерпретация цветного ювелирного камня. Перламутр имеет зависящие от угла отражения. Рисунок тёмных, красных и светлых поделочных вставок сохранён из фотографий.

## Точность и принятые решения

Это визуальная реконструкция по двум фотографиям и двум normal map, не скан изделия и не производственная CAD-модель. Глубина, посадка камней, реальная толщина и профиль торца на этих фотографиях не измеряются. Normal map описывает направление нормалей, а не абсолютную высоту; высота микрорельефа интерпретирована.

Маска исправлена по красной разметке пользователя (source/user-cutout-correction.png). Вырезаны только молочные участки внутри диагональной полосы: два небольших веера и промежутки вокруг центрального золотого орнамента. Серо-молочные поля с ветвями и розовыми камнями являются сплошными поделочными вставками и полностью восстановлены. Золотые линии и оправы сохранены. Дополнительных поддерживающих перемычек не добавлено. Контуры маски доступны для проверки и корректировки.

Карты материалов получены из фотографий и являются приближением. Фотографии содержат снятые блики и тени, поэтому абсолютная оптическая точность и точные породы полудрагоценных камней не заявляются. Для утверждения окончательного выставочного цифрового двойника нужно сверить контуры отверстий и толщину с владельцем изделия либо с замерами / макрофото торца.

Проверка корпуса Blender: 0 неманифолдных рёбер. Детальные численные показатели находятся в `output/metrics.json`. Предыдущий просмотрщик в корне проекта не изменён.

## Пересборка

Из папки exhibition в Ubuntu:

```sh
python3 prepare.py
tools/blender-4.5.3-linux-x64/blender -b --python build_blender.py
```

Параметры габарита, маска, высоты и критерии выделения материалов доступны в скриптах. Рекомендуется сохранить копию результата перед изменением параметров.

## Обновление плавности торцов

Внешний контур и все вырезы имеют геометрически округлённые переходы с обеих сторон: радиус наружного перехода 0,16 мм, внутреннего 0,10 мм. Стенки слегка выпуклые, скруглённые плечи выполнены материалом полированного золота без белого фотографического фона. Материал металла отражает окружение с шероховатостью 0,135. В просмотрщике добавлены узкие студийные источники, ползунок «Поворот света» и кнопка «Ракурс торца». Контуры вырезов остаются в согласованной диагональной полосе.




Последняя коррекция цвета золота и распознавания сапфиров отменена по просьбе пользователя. Восстановлены карты материалов и 504 камня из версии до этой коррекции. Скругления, исправленные вырезы и свободное вращение сохранены. Скрипт correct_materials.py оставлен как архив эксперимента; при сборке не запускать.

## Очистка остатков белого фона

По новой разметке пользователя уточнены только центральные отверстия. Границы доведены до оправ и сглажены периодическими кривыми; удалены белые колпачки, узкие светлые полосы и два малых остатка фона внутри орнамента. Проверены обе стороны. Исходные текстуры всех материалов и файл камней побайтно сохранены (11 защищённых файлов); корпус остаётся замкнутым. Исходное состояние геометрии сохранено в output/before-rim-cleanup. Для воспроизведения этой правки после prepare.py запустите clean_cutout_rims.py и rebuild_clean_cutouts.py, затем build_blender.py.
